### The CI/CD Pipeline Anatomy

This repo exists to explain the CI/CD pipeline as a structural reference: what happens at each phase, and why the stages are ordered the way they are. It's meant as a place to think through the logic behind the pipeline, not as a tutorial or a working implementation.

![Pipeline Anatomy Diagram](CICD-pipeline-anatomy.svg)

For an interactive version of this diagram, visit [CI/CD Pipeline Anatomy](https://nikhilvirdi.github.io/Pipeline-Anatomy/), and for its codebase, visit [Pipeline-Anatomy](https://github.com/nikhilvirdi/Pipeline-Anatomy).

For the static version, visit [CICDPipeline.png](CICDPipeline.png) — the exact draw.io diagram is also available as [CICDPipeline.drawio](CICDPipeline.drawio).

The diagram is built using: React, React Flow, and Tailwind CSS.
And deployed using: GitHub Actions and GitHub Pages.
